# 🏗️ Stack Tower – HTML5 Game (Phaser 3)

A **timing-based stacking game** built with **Phaser 3**, inspired by classic arcade stack games.  
The goal is simple: **drop moving blocks at the right moment to build the tallest tower possible**.

🎮 **Playable on desktop & mobile (portrait mode)**  
🔊 Includes sound effects, particles, smooth camera motion, and responsive UI.

## 🕹️ Gameplay

- A block moves left ↔ right at the top of the tower
- Tap / click to drop the block
- If aligned:
  - The overlapping part stacks
  - The extra part trims and falls
- If missed completely:
  - Game Over
- Score increases with each successful stack
- **Perfect placements** trigger special particles & sound effects
